# 📋 Smart To-Do List (React & Context API) 

## Overview
An interactive task management application built using ReactJS. This project is specifically designed to demonstrate the application of **Component-Based Architecture** principles and modern frontend structuring best practices.

The application features highly efficient state management utilizing the **React Context API** to ensure both scalability and maintainability, showcasing a strong grasp of core modern frontend fundamentals.

## 🌐 Live Demo
[View the live application here](https://omarrehan777.github.io/todo-list-react/)

## ✨ Key Features

* **Responsive Design:** Functions efficiently and maintains an attractive appearance across all screen sizes.
* **Clean State Management:** Utilizes **Context API** for centralized and effective state management, avoiding deep prop drilling.
* **Comprehensive Task Handling:** Easily add, edit, and delete tasks.
* **Task Filtering:** Sort tasks based on their status (Completed, Pending, All).
* **UI Components:** Integration of the Material UI (MUI) library for robust, pre-styled components.

## 🚀 Tech Stack

| Category | Technology |
| :--- | :--- |
| **Main Library** | ReactJS (Hooks & Components) |
| **Language** | JavaScript (ES6+) |
| **State Management** | React Context API |
| **UI Library** | Material UI (MUI) |
| **Build Tool** | Vite |

## ⚙️ Local Installation

Follow these steps to run the project on your local machine:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/OmarRehan777/todo-list-react.git](https://github.com/OmarRehan777/todo-list-react.git)
    cd todo-list-react
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Start the development server:**
    ```bash
    npm run dev
    ```
    The application will be available on the local link shown in your terminal.
